# RAG Playground — Workflow UI (v2)

React + Vite + [@xyflow/react](https://reactflow.dev/) node canvas. Uses the same FastAPI backend as `../frontend` (Angular).

## Dev

```bash
cd frontend_v2.0
npm install
npm run dev
```

Opens on [http://localhost:5173](http://localhost:5173). Ensure the backend is running on port 8000.

## Build

```bash
npm run build
```

Output in `dist/`.
